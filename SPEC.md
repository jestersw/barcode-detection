# Вариант 2: Устройство для считывания штрихкодов на конвейере

## Задача

Придумать программно-аппаратный комплекс, который решает задачу считывания
штрихкодов, наклеенных на картонные коробки.

## Вводные

Есть конвейер шириной **650 мм**, по которому движутся картонные коробки со
скоростью **1 м/с** и интервалом между коробками в **2 секунды**.

<!-- изображение: фото роликового конвейера с коробкой -->

- Размер коробок: **600 × 400 × 400 мм**.
- На коробках наклеены штрихкоды.
- Штрихкоды могут быть произвольно наклеены на любую грань коробки.

<!-- изображение: пример штрихкода на грани коробки -->

### Размер штрихкода

<!-- изображение: чертёж штрихкода с размерами -->

| Параметр                | Значение |
|-------------------------|----------|
| Полная ширина этикетки  | 78,00 мм |
| Ширина штрихкода        | 75,00 мм |
| Полезная ширина         | 60,00 мм |
| Боковые поля (quiet zone)| 7,50 мм каждое |
| Высота этикетки         | 25,00 мм |
| Высота штрихов          | 16,70 мм |
| Высота текста           | 7,30 мм  |

Пример содержимого: `КТЯ - 24652856131000`

Дополнительно:

- На одной коробке может быть наклеено несколько штрихкодов, в том числе
  несколько штрихкодов на одной грани.
- Для каждой из проезжающих коробок нужно считать **все** штрихкоды и передать
  их в систему управления конвейером, которая примет решение о сортировке
  коробки на основе считанных штрихкодов.
- Устройство можно разместить не дальше **трёх метров** от секции конвейера,
  которая сортирует коробки.

## Ожидаемый результат

- Выбран набор сенсоров и их характеристики, предложены конкретные модели
  сенсоров, обоснован выбор именно таких сенсоров.
- Определено физическое расположение выбранных сенсоров.
- Подобран вычислитель, обоснован выбор локальной и/или облачной обработки данных.
- Описан алгоритм считывания штрихкодов с момента сбора данных с сенсоров
  до момента отправки результатов считывания.
- При наличии нейросетей в предложенном алгоритме обоснован выбор конкретной
  архитектуры нейросетей и характеристики необходимого для обучения датасета
  (количество изображений, способ разметки, количество классов, способы
  аугментации и пр.).
- В случае использования готовых библиотек и/или фреймворков обоснован их выбор.
- Определены ключевые метрики оценки качества предложенного решения.
- Описана возможность масштабирования устройства для разных форм-факторов
  коробок и для разных типов штрихкодов.
- (Опционально) Реализована базовая версия предложенного алгоритма.
